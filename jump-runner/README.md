# 跳跳酷跑 🏃

一个用**原生 Canvas** 开发的微信小游戏：点击屏幕跳跃、支持二段跳，骑上心爱的坐骑，在无尽跑酷中躲避尖刺、木箱和深坑，收集金币，挑战最远里程。

- **可爱角色**：5 个 Q 版小人——阿杰（棒球帽）、小薄荷（双马尾）、柠檬少女（马尾辫裙）、葡萄少年（连帽卫衣）、樱子（丸子头裙），带眨眼、腮红、跑动摆臂、马尾/裙摆随跳跃飘动
- **坐骑系统**：小马驹 🐴 / 自行车 🚲 / 小摩托 🏍 / 小恐龙 🦖，各有专属特权，且都能**替你挡一次撞击**（撞击时坐骑逃跑，你继续跑）
- 昼夜循环背景：正午 → 黄昏 → 深夜 → 清晨，每 300 米切换时段（星空、月亮、渐变天空）
- **道具**：护盾（额外挡一次撞击）、磁铁（吸附金币）
- **个性商店**：角色/坐骑双标签，金币解锁，糖果风立体按钮 + 按压反馈（按下下沉变暗、松手触发）
- **排行榜**：好友榜（微信开放数据域 `openDataContext`，写入 `wx.setUserCloudStorage`）+ 本地记录 Top8；不支持的环境自动降级为本地记录
- 全程序化绘制，**零图片/音频素材**（音效由 WebAudio 振荡器合成）
- 本地存档：最高分、金币、角色坐骑、历史记录（含损坏兜底与旧档迁移）
- **打磨细节**：死亡顿帧+震屏、金币飞向计数器+计数器脉动、每 100 米里程碑横幅、转场淡入、画面暗角、雪山顶/松树/草丛/前景视差草、太阳旋转光芒
- 奖牌结算（铜 20m / 银 80m / 金 200m）

## 玩法与坐骑特权

| 操作 | 效果 |
| --- | --- |
| 点按**右半屏** | 跳跃 |
| 空中再点一次 | 二段跳（掉进坑里也能自救） |
| 点按/按住**左半屏**（或下滑手势） | 铲行（压低身体，从低空障碍下穿过） |
| 空中下滑 | 急坠 + 落地自动接铲行 |
| 铲行中点按右侧 | 取消铲行并起跳 |
| 撞到障碍 或 坠坑 | 游戏结束（护盾→坐骑→生命的顺序抵挡；坠坑无法抵挡） |

| 障碍 | 应对 |
| --- | --- |
| 尖刺 / 木箱 | 跳过 |
| 深坑 | 跳跃 / 二段跳 |
| 低空飞鸟 🐦 | 铲行穿过，或看准时机跳过 |
| 无人机广告牌 🚁 | 只能铲行通过（牌上箭头会提示下压） |
| 绿色平台箱 ⬆️ | 从上方落下可站上箱顶（顶上有金币奖励），侧面撞击会受伤 |

| 坐骑 | 特权 | 售价 |
| --- | --- | --- |
| 步行 | 轻装上阵 | 免费 |
| 小马驹 | 跳跃高度 +8% | 150 金币 |
| 自行车 | 磁铁时间 +50% | 150 金币 |
| 小摩托 | 速度 +8%（冲分更快） | 300 金币 |
| 小恐龙 | 开局自带护盾 | 300 金币 |

主菜单点「✦ 个性商店」用金币解锁角色和坐骑；金币在每局结束后自动入账。铲行时坐骑会一并压低。
**新玩家初始赠送自行车坐骑**，一进来就能体验骑行和坐骑抵挡。

## 在微信开发者工具中运行

1. 安装[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 打开工具 → **导入项目** → 目录选择本文件夹 `jump-runner`
3. AppID 选择「**测试号**」（`project.config.json` 里已配置 `touristappid`）
4. 编译运行即可游玩（**横屏游戏**，`game.json` 已锁定 `landscape`）；「真机调试」可扫码在手机上试玩

### 分辨率适配说明

游戏采用「设计高度」等比缩放：所有逻辑运行在 高度=500 的坐标系（`js/main.js` 的 `DESIGN_HEIGHT`），
设备实际高度决定缩放系数，实际宽度决定可见逻辑视野。横屏手机视野约 1080+ 逻辑像素；
改回竖屏只需把 `game.json` 的 `deviceOrientation` 改为 `portrait`。想让角色/场景再大或再小，
直接调 `DESIGN_HEIGHT`（数值越小画面越大、视野越近）即可，无需改其他代码。

### 换成自己的 AppID / 正式发布

1. 到 [mp.weixin.qq.com](https://mp.weixin.qq.com/) 注册**小游戏**账号（个人主体即可），拿到 AppID
2. 替换 `project.config.json` 中的 `appid`
3. 开发者工具右上角「上传」→ 在小程序后台提交**审核**，通过后发布

### 好友排行榜说明

主域在每次死亡时把最佳成绩写入 `wx.setUserCloudStorage`（key: `bestScore`），并 `postMessage` 通知开放数据域；
`openDataContext/game.js` 拉取 `wx.getFriendCloudStorage` 渲染好友名次到共享画布，主域在排行榜弹层里
`drawImage` 该画布。微信开发者工具中可用测试好友数据预览；浏览器预览自动降级为本地记录。

### 字体说明

全游戏 UI 使用[得意黑 Smiley Sans](https://github.com/atelier-anchor/smiley-sans)（免费可商用，运动斜体），
所有文字通过 `js/font.js` 的 `F.b(字号)` / `F.r(字号)` 获取字体字符串，加载失败自动回退系统字体。

- 浏览器预览：自动注入 npm 分片字体 CSS（cdn.jsdelivr.net，按需加载）
- 微信真机：默认尝试加载代码包内 `fonts/SmileySans-Oblique.ttf`——从官方 Releases 下载该文件放入
  `jump-runner/fonts/` 即可生效（约 1.6MB，注意主包体积限制，或改放分包）；也可自行改 `font.js` 走
  已备案 CDN 的网络字体方案

## 常用调参（`js/main.js` 顶部常量）

| 常量 | 含义 | 默认值 |
| --- | --- | --- |
| `BASE_SPEED` | 初速度（px/s） | 280 |
| `SPEED_GROW` | 每秒加速度 | 7 |
| `MAX_SPEED` | 速度上限 | 540 |
| `SCORE_DIV` | 多少 px 折算 1 米 | 55 |

- 跳跃力度：`js/player.js` 里 `jump()` 的 `-900`（一段）/ `-780`（二段），重力 `2500`
- 难度曲线：`js/main.js` 的 `diff()`（350 米拉满）与 `js/world.js` 的 `spawnPattern()`
- 道具出现概率：`js/world.js` 的 `spawnPattern()` 末尾（默认 9%）；磁铁时长：`js/main.js` 的 `MAGNET_SECONDS`
- 角色造型与配色：`js/skins.js`（`kind` 决定发型/服装）；坐骑与特权/售价：`js/mounts.js`
- 昼夜切换周期：`js/background.js` 的 `getTheme()`（每 300 米一个时段）；奖牌门槛：`js/ui.js` 的 `drawGameOver()`
